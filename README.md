Personal Portfolio — Starter (Vanilla HTML/CSS/JS)

What this is:
- A small dark-themed portfolio template using plain HTML, CSS, and JavaScript.
- Includes: About, Projects, Contact sections; Arial font; subtle reveal animations and a simple typewriter subtitle.

How to use:
1. Open index.html in your browser (double-click or right-click -> Open with).
2. Edit the file content (Your Name, About text, project details, email) to personalize.
3. Replace placeholder links in the Projects section with your demos or GitHub repos.
4. To publish: push this folder to GitHub and enable GitHub Pages (or upload to any static host).

Customization ideas:
- Swap fonts by linking Google Fonts in index.html.
- Replace color variables in styles.css to change theme.
- Add project thumbnails by adding <img> to each .card and adjusting CSS.
